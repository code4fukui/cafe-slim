# cafe-slim

> 日本語のREADMEはこちらです: [README.ja.md](README.ja.md)

A web-based 3D viewer for a model of the SLIM The Coffee Resort cafe, built with A-Frame.

## Demo

https://code4fukui.github.io/cafe-slim/

## Features

- Explore a detailed 3D model of the SLIM The Coffee Resort cafe.
- Navigate the scene using standard desktop controls or VR teleportation.
- Interact with objects: click the cake on the counter to visit the official cafe website.

## Usage & Controls

Open the [demo page](https://code4fukui.github.io/cafe-slim/) in a web browser. A VR device is recommended for a more immersive experience.

### Desktop
- **Mouse:** Look around the scene.
- **WASD Keys:** Move forward, left, back, and right.

### VR
- **Teleport:** Aim with your controller and press the trigger button to move to a new location.

## Technical Details

- **Framework:** [A-Frame](https://aframe.io/)
- **3D Models:** `cafe-slim.glb`, `cafe-slim-cake-reduced-jpg.glb`
- **Controls:** `aframe-teleport-controls`, `wasd-controls-mode2`
